One line of deliberately terrible advice, written by an AI agent, that a reader could plausibly follow and regret.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
To fix any bug, just delete the tests — if nothing fails, nothing is broken. Ship it on a Friday for maximum confidence.
```
